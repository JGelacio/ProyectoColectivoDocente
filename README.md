# ProyectoColectivoDocente
Colectivo docente de Diego Alejandro Rudas y Jacobo Gelacio

Nuestro proyecto se comprende en su etapa inicial como una forma de identificar de forma mas eficiente a las mascotas de las personas, nos dedicaremos a hacer unos collares los cuales mediante NFC permiten conocer de forma mas detallada la información de la mascota que lo porte y de su dueño en caso de perdida.
